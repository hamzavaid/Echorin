# Echorin v1.1 — Visualization & Engineering UI

This release turns the v1.0 dashboard into a dockable engineering workspace.
The same Radar/Sonar sensing, matched filtering, CA-CFAR, Doppler, Kalman
tracking, scenario recording, and export pipelines remain in place.

## Added

- Movable, resizable, hideable docks for scenario/sensor controls, tracks,
  signal plots, Range-Doppler heatmap, inspector, and diagnostics. Layout and
  dark/light theme persist between launches; PPI focus mode is reversible.
- Full `[velocity, range]` Range-Doppler heatmap from the existing Doppler FFT,
  with physical units, dB/linear scale, colorbar, detection overlay, adjustable
  view limits, hover readout, and selected-cell inspection. A selected cell also
  updates the existing 1D spectrum.
- PPI labels, lifecycle-specific markers, velocity vectors, 95% position
  covariance ellipses, legend, and individual visibility toggles.
- Measurement/track inspector with sensor-derived range, bearing, radial
  velocity, Cartesian estimate, SNR, amplitude, confidence, source bin, track
  status, velocity, and covariance where available.
- Live timing and count diagnostics for simulation, sensing, DSP, tracking,
  GUI refresh, and full frame.
- Sonar display refresh floor increased to 400 ms after measuring the larger
  v1.1 heatmap workload; simulation-time step remains independently configured.

## Validation and limits

The release tests cover physical Range-Doppler coordinates in both Radar and
Sonar modes, dB edge cases, covariance eigen geometry, selection state, GUI
smoke behavior, and all v1.0 regressions. The image transform does not affect
detector or tracker numerical output. The existing angular channel is still an
idealized directional measurement; receiver arrays and signal-derived DOA are
planned for v1.2 and are not claimed here. Propagation remains an educational
point-target model with simplified attenuation, AWGN, and no clutter/multipath.
