# Echorin v1.2 — Receiver Arrays and Direction Finding

The production Radar and Sonar frame now synthesizes one composite eight-element
ULA observation, with shape `[element, pulse, fast-time sample]`. Each target's
physical element phase and delayed/Doppler echo are accumulated before receiver
noise. FFT matched filtering, Bartlett beamforming, CA-CFAR range candidates,
angular peak finding, and the existing Doppler/tracker path produce truth-free
range/bearing/velocity detections. The old idealized directional acquisition
methods remain only as compatibility APIs.

The dockable Range-Angle map shows `[bearing, range]` power with physical units,
dB/linear display, a colorbar, detection markers, and cell inspection. The
same-range two-target benchmark is reproducible with
`python benchmarks/run_array_benchmark.py`.

The model uses a far-field narrowband phase approximation, one pulse snapshot
for the live angle map, point reflectors, and a front/back ambiguous ULA. It
does not claim calibrated array hardware or environmental propagation realism.
