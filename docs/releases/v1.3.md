# Echorin v1.3 — Moving Sensor Platforms

v1.3 builds on the v1.2 composite-array receiver without adding the v1.4
environmental or beam-pattern models.

- Timestamped platform position, velocity, acceleration, heading and yaw rate;
  body-frame sensor mounts include rotational offset velocity.
- Stationary, constant-velocity, constant-acceleration, coordinated-turn and
  waypoint trajectories advance on the deterministic world clock.
- Radar and Sonar echo synthesis use moving-receiver range rate. Array bearings
  remain sensor-local until the timestamped receiver pose transforms them to
  world coordinates for tracking and display.
- A dockable platform editor configures motion, mount, waypoints and array
  geometry. The PPI can show the platform path, heading and array field of view.
- Scenario and frame JSON use schema version 2 while accepting legacy
  unversioned files. Frame records retain platform/receiver pose without a
  detection.
- `benchmarks/run_platform_benchmark.py` reports seeded analytic-vs-measured
  range, bearing and radial-velocity errors with physical bin tolerances.

The coherent frame still uses a fixed receiver pose during its pulse train
(stop-and-hop). The uniform linear array retains front/back ambiguity and a
receiver-local -90 to +90 degree scan. No clutter, multipath, beam pattern,
environmental propagation or v1.4 feature is implied by the PPI field-of-view
guide.

Post-release detection stability: the Crossing preset now keeps both targets
in the ULA's observable front half-plane and separates their path-crossing
times. Known-waveform matched-filter residual rejection and noise-calibrated
angular peaks prevent sidelobes or a noise range bin from becoming multiple
tracks. Association and Kalman correction use range-scaled bearing covariance;
the legacy fixed-variance tracker API remains supported.
The Single preset now uses the 1.5-km Radar scenario distance instead of an
override to 100 m. The production GUI uses edge-adaptive CA-CFAR so an
explicit 100-m Radar target is also detectable; the detector's legacy masked-
edge default remains available for compatibility.
