# v1.4 — Environmental and Propagation Realism

Adds seeded, selectable environmental effects before the existing Radar/Sonar
DSP and tracking chain. Empty environment and isotropic beam defaults preserve
the v1.3 baseline, including Crossing/Single regressions and replay/export.

- Pluggable AWGN, stationary colored Gaussian AR(1), sparse impulsive noise,
  and equicorrelated array noise, with statistical tests.
- Coherent narrowband interference, optional drift and array arrival angle.
- Persistent distributed clutter and separate acoustic reverberation presets.
- Direct plus delayed multipath with attenuation, phase and angle offsets.
- Isotropic, sector, Gaussian and aperture-sinc beam patterns applied to signals.
- Fixed, rotation, sector ping-pong/reset and step/dwell scan scheduling.
- Environment dock, medium-scaled templates, validation errors, beam overlay
  toggle, status information, and scenario schema 3 (schema 1/2 migration).
- Numerical model, raw-acquisition, detector/tracker, GUI, responsiveness,
  serialization and regression coverage; reproducible environmental benchmark.

## Engineering decisions and approximation limits

The same co-located transmit/receive beam applies twice to point echoes, once
to incident angular interference. Common-mode injection bypasses antenna gain.
Each CPI holds boresight and geometry fixed. Clutter density is per range metre,
with a default safety limit of 2,048 scatterers per field; unsafe density raises
an error rather than truncating or silently simplifying the model. Moving field
speeds and receiver motion must respect the existing unambiguous Doppler limit.
AR(1) and equicorrelated models expose explicit spectral/covariance parameters,
not arbitrary PSD/matrix editors. Secondary paths have fixed extra length and
inherit direct-path Doppler. No terrain ray tracing or bistatic features were added.

The GUI has typed common controls and editable JSON lists for multiple tones,
clutter fields and multipath components. Templates are examples, not calibrated
operating environments. Apply pauses/restarts the scenario; invalid edits or
incompatible mode switches leave prior sensor configuration unchanged. Scenario
files describe fresh seeded scattering fields, not live field-state checkpoints.

Receiver AWGN retains its original seed sequence. A separate field seed stream
prevents clutter from consuming receiver-noise randomness. Changing noise kind
changes that model's sequence intentionally. No truth-aware detector correction,
second Doppler pipeline, v1.5 bistatic processing or v1.6 CFAR was introduced.

## Validation and evidence

Run `python benchmarks/run_environment_benchmark.py` for complete seed, physical
configuration, environment/beam settings, per-frame detection counts, target and
ghost hit counts, bin-scaled errors and processing times. Runtime is reported,
not constrained by brittle CI wall-clock assertions. See [scenarios](../scenarios.md),
the [CA-CFAR comparison](../../benchmarks/environment_comparison.svg) and
[workspace capture](../../screenshots/echorin-environment.png). Core statistical
tests validate variance, AR(1) PSD, impulse rate/amplitude and receiver covariance;
end-to-end tests verify resolvable ghosts in both sensing modes. Qt heartbeat
tests use an acquisition gate to prove responsiveness without scheduling races.

Release gate on Windows/Python 3.14: 184 tests and Ruff pass in the project
environment and a fresh non-editable wheel installation. Native Qt windows
published Radar and Sonar worker frames from the installed package. Public
captures were visually checked; private specifications/handoff files remain ignored.

Seed-7/four-frame benchmark baseline error was 4.30 m in Radar (14.99-m bins)
and zero range error in Sonar (0.0078-m bins); bearing and stationary Doppler
fit one bin. The scan case detected the target on two of four dwells in each
mode. The moderate Radar multipath template stayed below detection threshold;
the Sonar template published a delayed echo on all four frames. Separate
high-SNR integration tests resolve direct/secondary paths in both modes.
Correlated Sonar noise and reverberation produced extra measurements, as
expected when CA-CFAR independence assumptions no longer hold.

Observed default-scale capture totals were roughly 40–60 ms in Radar with
colored noise/multipath and 740–960 ms in Sonar with the 20-source reverberation
template, including GUI refresh. These are local measurements, not hardware
guarantees. The GUI worker keeps interaction responsive and bounds the queue;
simulation time advances by configured dt rather than attempting wall-clock
catch-up. Occupied-span accumulation preserves dense-reference samples while
avoiding full-sized zero temporary arrays for each scatterer.
